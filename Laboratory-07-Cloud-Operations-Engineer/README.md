# Laboratory 07 - The Cloud Operations Engineer

## Mission Overview

In this laboratory, I acted as a Cloud Operations Engineer. My task was to monitor the Linux server and Docker containers to make sure they were running properly. I used different Linux and Docker commands to check system resources, container logs, and performance.

## Objectives

- Understand the importance of monitoring cloud servers and containers.
- Check the CPU, memory, and disk usage of a Linux server.
- Use Linux commands to monitor system performance.
- View Docker container logs to identify errors.
- Monitor Docker container CPU and memory usage.
- Learn basic troubleshooting in cloud environments.

## Monitoring Commands Executed

```bash
uptime
free -h
df -h
top
docker ps
docker logs client-website
docker stats
docker stats --no-stream client-website
```

## Skills Learned

- Learned how to check Linux server resources.
- Understood how CPU and memory usage affect server performance.
- Learned how to view Docker container logs.
- Used Docker commands to monitor container performance.
- Improved my troubleshooting skills in Linux.
- Understood why monitoring is important in cloud operations.
