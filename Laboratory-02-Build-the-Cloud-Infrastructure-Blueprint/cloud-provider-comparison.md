# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 (object), EBS (block) | Blob Storage, Managed Disks | Cloud Storage, Persistent Disk |
| Networking | Amazon VPC | Azure Virtual Network (VNet) | VPC Network |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID + Azure RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

Amazon Web Services (AWS) offers the broadest range of cloud services among the three providers. It provides many solutions for computing, storage, networking, databases, security, and artificial intelligence. These services make AWS suitable for different types of businesses and organizations.

### 2. Which platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with existing Microsoft products and technologies. It provides strong integration with Windows Server, Microsoft 365, and Microsoft Entra ID. This makes it easier for organizations to manage their systems and migrate services to the cloud.

### 3. Which platform is widely recognized for AI, ML, and Kubernetes services?

Google Cloud Platform (GCP) is widely recognized for its artificial intelligence, machine learning, and Kubernetes services. It offers Vertex AI for developing machine learning applications and Google Kubernetes Engine (GKE) for managing containerized applications. These services help businesses develop and manage modern applications efficiently.

### 4. What similarities did you observe among the three providers?

AWS, Microsoft Azure, and Google Cloud Platform all provide cloud computing services that can be accessed through the internet. They offer similar infrastructure components such as virtual machines, storage, networking, and identity management. All three platforms help businesses reduce the need for physical servers, improve scalability, and manage their IT resources more efficiently.
