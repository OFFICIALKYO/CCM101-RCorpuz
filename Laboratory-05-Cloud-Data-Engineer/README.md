# Laboratory 05 - Cloud Data Engineer

## Mission Overview
In this mission, I worked as a Cloud Data Engineer at CloudNova Technologies. I compared Block, File, and Object Storage, then deployed MinIO, an S3-compatible object storage server, using Docker on a KillerCoda Playground. I accessed its web console through port forwarding, created a bucket named `client-photos`, and uploaded a test file as a proof of concept for a photo-sharing application.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server (MinIO) using Docker.
- Access a cloud service via a web interface using port forwarding.
- Create a storage bucket and upload objects (files) to the cloud.
- Document cloud storage operations using Markdown.
- Continue expanding a professional GitHub Cloud Computing Portfolio.

## Tools Used
- KillerCoda Ubuntu Playground
- Docker
- MinIO (S3-compatible object storage)
- Git and GitHub
- Markdown
- Web browser

## Skills Learned
- Explaining the differences between block, file, and object storage
- Deploying a containerized service using Docker environment variables
- Accessing a cloud service on a specific port through a browser
- Creating a bucket and uploading objects
- Documenting technical configurations in Markdown
- Maintaining a structured GitHub repository with commits per checkpoint
