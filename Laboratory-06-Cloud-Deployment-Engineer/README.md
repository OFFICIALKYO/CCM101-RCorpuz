# Laboratory 06 - The Cloud Deployment Engineer

## Mission Overview

In this laboratory, I learned how to deploy a web application and database using Docker Compose. I created a YAML file to configure the containers and run them together. This activity helped me understand how applications and databases communicate in a cloud environment.

## Objectives

1. Understand how Docker Compose works.
2. Create and configure a docker-compose.yml file.
3. Deploy a web application and MySQL database using containers.
4. Learn how to start, check, and stop Docker containers.
5. Upload my laboratory files to GitHub.

## Commands Executed

- `mkdir` - Used to create a new directory for the laboratory.
- `cd` - Used to navigate to the project directory.
- `nano` - Used to create and edit files in the terminal.
- `docker-compose up -d` - Used to start the containers in the background.
- `docker-compose ps` - Used to check the status of the running containers.
- `docker-compose down` - Used to stop and remove the containers.
- `git add .` - Used to stage the files for Git.
- `git commit -m "Complete Laboratory 06"` - Used to save the changes in the repository.
- `git push` - Used to upload the files to GitHub.

## Skills Learned

In this laboratory, I learned how to use Docker Compose to manage multiple containers using one YAML file. I also learned how to connect a PHP application to a MySQL database using service names. I improved my Linux terminal skills by using commands to create and edit files. I also practiced using Git and GitHub to save and upload my laboratory activities.
