# Laboratory 01 – Welcome to the Cloud

## Mission Overview
As a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, my first mission was to work inside a Linux environment using the KillerCoda Playground, document my work in Markdown, and build a version-controlled Cloud Computing Portfolio on GitHub.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
1. Launched an Ubuntu 24.04 playground on KillerCoda and verified the terminal.
2. Created a new user (`rcorpuz`) with Bash, a home directory, and sudo, then logged in.
3. Recorded the username, working directory, and hostname.
4. Gathered system information (distribution, kernel, CPU, memory, disk) into `system-information.md`.
5. Created the Documents, Notes, Reports, and Screenshots folders and wrote `about-me.md`.
6. Cloned the GitHub repository, built the portfolio structure, and wrote the README files.
7. Added screenshots as evidence and pushed everything to GitHub.

## Linux Commands Used
| Command | Purpose |
|---------|---------|
| `useradd` | Create a new user |
| `chpasswd` | Set a user's password |
| `su` | Switch user |
| `whoami` | Show current username |
| `pwd` | Show current working directory |
| `hostname` | Show hostname |
| `uname -r` | Show kernel version |
| `lscpu` / `nproc` | Show CPU information |
| `free -h` | Show memory |
| `df -h` | Show disk space |
| `mkdir -p` | Create directories |
| `cat` | Create/view files |
| `cp` | Copy files |
| `ls` / `cd` | List and navigate |
| `git clone/add/commit/push` | Version control |

## Skills Learned
- Navigating the Linux terminal
- User and permission management basics
- Gathering system information
- Creating and organizing files and directories
- Using Git and GitHub for version control
- Writing professional documentation in Markdown
