# Reflection

In this laboratory activity, I learned how to work inside a Linux environment using the KillerCoda Playground. I created a new user, explored system information, and organized files and folders using the command line.

I also learned how to build a version-controlled portfolio on GitHub and document my work using Markdown. The hardest part was remembering the commands and the order of the steps, but repeating them helped me understand how a cloud engineer works in a terminal.

This lab showed me that good documentation is just as important as the technical work itself. I look forward to using this portfolio for Docker, Kubernetes, and the other upcoming labs.
