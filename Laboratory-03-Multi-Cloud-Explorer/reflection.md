# Checkpoint 8 – Mission Reflection

## My Cloud Computing Mission Reflection

After completing this cloud computing mission, the cloud platform that impressed me the most is Amazon Web Services (AWS). I like AWS because it offers many useful services such as EC2 for virtual servers, S3 for file storage, and RDS for database management. I also learned that AWS can help businesses run applications and store information without maintaining physical servers.

AWS, Microsoft Azure, and Google Cloud Platform have many similarities. All three provide cloud computing services such as virtual machines, storage, networking, databases, and identity management. They also allow businesses to access computing resources through the internet. Although they have different tools and features, they all help organizations manage their technology more efficiently.

Business requirements are important when choosing a cloud platform. Companies need to consider their budget, security, storage needs, performance, and the type of applications they want to use. For example, a company that already uses Microsoft products may prefer Azure, while a business that needs different cloud services may choose AWS. Organizations focused on artificial intelligence and data analytics may also consider Google Cloud.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud platform requires understanding the needs and goals of a business. I learned that there is no single cloud platform that is perfect for every organization. A good consultant must compare services, advantages, costs, and business requirements before making a recommendation.

My GitHub Cloud Computing Portfolio has improved after completing this mission because I added research, comparisons, and documentation about AWS, Azure, and Google Cloud. I also improved my knowledge of Markdown, Git commands, and GitHub. This mission helped me understand cloud computing better and gave me more confidence in using cloud technologies for future projects and my career in Information Technology.
