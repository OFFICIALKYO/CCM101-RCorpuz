

# Checkpoint 4 – Cloud Platform Recommendation Challenge
## Client A – Startup Company

**Recommended Cloud Platform: Amazon Web Services (AWS)**

I recommend AWS because it offers affordable and flexible cloud services that are suitable for startup companies. The company can start with small computing resources to save money and increase them as the number of application users grows. AWS also provides different tools that can help developers build, manage, and maintain their mobile applications. This makes AWS a good choice for a startup that expects rapid business growth.

**Recommended Services:**

1. **Amazon EC2:** Provides virtual servers for running the application's backend.
2. **Amazon S3:** Stores application files, images, and other important data.
3. **Amazon RDS:** Manages the application's relational database.
4. **AWS Lambda:** Runs application code without managing physical servers.

## Client B – University

**Recommended Cloud Platform: Microsoft Azure**

I recommend Microsoft Azure because the university already uses Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with these existing systems, making cloud migration easier to manage. It also offers security and identity management features that can help protect university information and resources. This platform is suitable for a university that wants to move some of its services to the cloud.

**Recommended Services:**

1. **Azure Virtual Machines:** Allows the university to run Windows Server workloads in the cloud.
2. **Microsoft Entra ID:** Manages user identities and access to university resources.
3. **Azure Blob Storage:** Stores university documents, files, and backups.
4. **Azure SQL Database:** Manages databases for university applications.

## Client C – AI Research Company

**Recommended Cloud Platform: Google Cloud Platform (GCP)**

I recommend Google Cloud Platform because it provides powerful artificial intelligence and machine learning services. These services can help the research company develop, train, and deploy AI and machine learning applications. Google Cloud also provides computing resources that can handle demanding research workloads. This makes it a suitable platform for a company that needs high-performance computing.

**Recommended Services:**

1. **Vertex AI:** Helps developers build, train, and deploy machine learning models.
2. **Compute Engine:** Provides virtual machines for high-performance computing workloads.
3. **Google Kubernetes Engine (GKE):** Manages and deploys containerized AI applications.
4. **Cloud Storage:** Stores large datasets, research files, and machine learning data.

## Client D – Global E-Commerce Company

**Recommended Cloud Platform: Amazon Web Services (AWS)**

I recommend AWS because it has a global infrastructure that can support an online shopping company serving customers from different countries. It provides automatic scaling and load balancing to handle changes in website traffic, especially during promotions and busy shopping seasons. AWS also offers storage and database services that help manage product information and customer transactions. These features make AWS a suitable platform for a global e-commerce business that requires high availability and reliable performance.

**Recommended Services:**

1. **Amazon EC2 Auto Scaling:** Automatically increases or decreases computing resources depending on website traffic.
2. **Elastic Load Balancing (ELB):** Distributes incoming traffic across multiple servers.
3. **Amazon CloudFront:** Delivers website content to customers through a global content delivery network.
4. **Amazon RDS:** Manages product, customer, and transaction databases.
5. **Amazon S3:** Stores product images, documents, and other website files.




Checkpoint 6 – Multi-Cloud Decision Matrix

Business Requirement | Recommended Platform | Justification
---------------------|----------------------|-------------
Startup Company | AWS | AWS provides a wide range of scalable and flexible services that allow startups to begin with smaller resources and expand as their applications grow.
Enterprise Organization | AWS | AWS provides a broad selection of enterprise services, strong security features, global infrastructure, and scalable resources for complex workloads.
Microsoft Environment | Microsoft Azure | Azure provides strong integration with Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft technologies.
AI / Machine Learning | Google Cloud Platform | Google Cloud provides strong artificial intelligence and machine learning services, including Vertex AI and high-performance computing resources.
Kubernetes Deployment | Google Cloud Platform | Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes platform designed for deploying, managing, and scaling containerized applications.
Global Web Application | AWS | AWS provides global infrastructure, automatic scaling, load balancing, content delivery, and other services that support highly available web applications.

Decision Matrix Summary

1. Startup Company – AWS is recommended because it provides scalable services and a large selection of tools suitable for growing businesses.

2. Enterprise Organization – AWS is recommended because of its broad service portfolio, security capabilities, scalability, and global infrastructure.

3. Microsoft Environment – Microsoft Azure is recommended because it integrates strongly with existing Microsoft technologies.

4. AI / Machine Learning – Google Cloud is recommended because of its strong AI, machine learning, and data analytics capabilities.

5. Kubernetes Deployment – Google Cloud is recommended because Google Kubernetes Engine provides a managed Kubernetes environment for containerized applications.




## Conclusion

Each cloud platform has different strengths depending on the needs of a business or organization. AWS is recommended for the startup company and global e-commerce company because of its flexible services and scalability. Microsoft Azure is suitable for the university because of its integration with Microsoft technologies. Google Cloud Platform is recommended for the AI research company because of its artificial intelligence, machine learning, and computing capabilities. Choosing the right cloud platform depends on the organization's budget, existing technology, and business requirements.
